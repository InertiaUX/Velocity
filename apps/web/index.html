Install

Download the build for your platform, then finish onboarding.

  1. Download from the button above (or Other platforms on GitHub Releases).
  2. macOS: unzip and drag Velocity.app into Applications. Windows: run the installer. Linux: run the AppImage or install the .deb.
  3. On macOS, if Gatekeeper blocks an unsigned build: right-click → Open → Open.

Then finish onboarding. Hide and show with Shift + Tab.

Help Velocity become signed

Velocity is free. A signed Mac build needs an Apple Developer account and notarization. If you want to chip in, it goes toward that so downloads can open with a normal double-click.
